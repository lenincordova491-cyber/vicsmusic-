# Política de Privacidad de Vicsmusic

Vicsmusic está comprometida con la privacidad absoluta del usuario:
1. **Sin rastreadores ni telemetría:** La aplicación no incluye bibliotecas de analítica ni rastreo de terceros.
2. **Almacenamiento Local:** Los favoritos, listas de reproducción y preferencias se almacenan exclusivamente en la base de datos local de tu dispositivo.
3. **Cero Publicidad:** La app no contiene anuncios ni se conecta a redes de monetización publicitaria.
