# Guía de Contribución para Vicsmusic

1. Toda contribución debe respetar la arquitectura por capas y la modularización en Gradle.
2. Cada nueva funcionalidad debe ir acompañada de sus pruebas unitarias.
3. Todo código nuevo debe pasar `./gradlew testDebugUnitTest` y los linters correspondientes.
4. No se admite inclusión de código bajo licencias restrictivas (GPL) ni dependencias que contengan publicidad o rastreadores.
